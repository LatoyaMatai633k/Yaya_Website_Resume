## Style

- Use white or warm-white as the main background.
- Explore a solid burgundy-and-pink palette or a nude-and-beige palette before finalizing the accent colors.
- Use dark text, solid color sections, and clear typography.
- Avoid gradients, floating blobs, glassmorphism, excessive animation, and generic AI-template styling.
- Use subtle shadows on buttons and selected cards.
- Keep borders and rounded corners restrained and consistent.
- Make the design professional, distinctive, and recruiter-friendly.
- Prioritize mobile-first responsive design.
- Include a light/dark theme only if it can be implemented without compromising the core website.

## Other Sections

## Technical Requirements

- Use plain HTML, CSS, and JavaScript.
- Create `index.html`, `styles.css`, and `script.js` inside the portfolio folder.
- Do not use frameworks, external packages, a build step, or a backend for the initial version.
- Make the site responsive, accessible, keyboard-friendly, and easy to navigate.
- Ensure buttons, navigation, and implemented interactions work correctly on mobile and desktop.
- Create a polished foundation with clearly designed placeholders for the signature pose, CV download, and Ask Yaya assistant.    
Do not build the advanced versions tonight.
- Do not invent project features, qualifications, certificates, achievements, contact details, or repository URLs.
- Clearly distinguish independent projects, tutorial-based projects, and collaborative work.
- Do not make changes to AWS resources while generating the website.
- Prepare the website for a public GitHub repository and deployment using AWS Amplify Hosting.

## Portfolio Goal

Create a distinctive, professional portfolio that demonstrates my development skills, learning journey, project contributions, and personality. It should be memorable because of its thoughtful design and meaningful interactions, not because it relies on trendy visual effects.
